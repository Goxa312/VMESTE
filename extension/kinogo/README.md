# Вместе — Киного

Расширение Manifest V3 для Chrome/Edge 116+. Каждый участник устанавливает свою копию. Это дополнение к комнате «Вместе», а не отдельный каталог видео.

## Обновление до 0.2.1

Если расширение загружено из обновлённой папки проекта `extension/kinogo`, нажмите ↻ у него на `chrome://extensions` / `edge://extensions`. Для установки из ZIP сначала распакуйте новый архив с заменой файлов в установленную папку. Проверьте версию 0.2.1. Уже открытые страницы приложения подключаются автоматически; при необходимости нажмите значок «Вместе» → «Восстановить связь». После обновления со старой версии перезагрузите вкладку фильма, если в ней осталась старая панель.

В 0.2.1 ссылки на страницы комментариев открывают основную страницу фильма. Если вкладка Киного не ответила за 20 секунд, комната показывает пояснение и повторную загрузку в той же вкладке. Обычные и инкогнито-вкладки не смешиваются. Это не устраняет сбои загрузки самого сайта: если Киного работает только в инкогнито, проверьте сохранённые данные сайта и другие расширения обычного профиля Chrome.

Версия 0.2.0 поддерживает опубликованный сайт и в исходной папке, и в ZIP. Добавлены окно состояния по значку расширения, восстановление связи без перезагрузки комнаты, повторное использование открытого фильма, проверка установки/версии и сворачиваемая панель плеера. Обновление страницы комнаты не разрывает привязку фильма.

## Установка

1. Распакуйте ZIP или используйте эту папку `extension/kinogo`.
2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите режим разработчика → «Загрузить распакованное расширение» → выберите папку с `manifest.json`.
4. Откройте/перезагрузите комнату по адресу вашей сборки в том же профиле браузера. Для локальной версии это `http://127.0.0.1:5173` или `http://localhost:5173`.
5. Добавьте обычную ссылку на страницу фильма с `kinogo.my`, нажмите «Смотреть на Киного».
6. Запустите фильм. Играющее видео длительностью от 10 минут подключится после 3 секунд стабильного источника. Для коротких роликов или выбора другого видео нажмите «Подключить это видео» после рекламы.

У ведущего запуск, пауза и перемотка передаются через API комнаты. Участники следуют общему времени; звук остаётся локальным. Вкладку комнаты оставляйте открытой. При смене фильма подключите новую вкладку. «Отключить», закрытие комнаты или переход на другой фильм отключают сессию; вкладка Киного не закрывается.

## Доступ и ограничения

- Content scripts работают только на локальном приложении, `https://vmeste.dadvanigeorgii.workers.dev`, `kinogo.my`, `www.kinogo.my` и плеере `kinogomy.stravers.live`. В коде дополнительно проверяются origin, идентификатор комнаты, вкладка и выбранный фрейм. Разрешение `scripting` нужно для восстановления подключения в уже открытых вкладках этих сайтов.
- Ключ комнаты, сообщения чата и участники не передаются расширению или Киного. Авторизованные API-запросы выполняет вкладка приложения. Сервис расширения сам не делает сетевых запросов.
- Временная привязка вкладок хранится в `chrome.storage.session`. При перезапуске браузера подключите просмотр снова.
- Автоматический выбор консервативный: нужен играющий видимый HTML5-плеер, конечная длительность от 10 минут и стабильный источник в течение 3 секунд. Короткие ролики и неоднозначные случаи подключайте вручную. Это эвристика, а не распознавание рекламы. Автовыбор не заменяет уже выбранный плеер в другом фрейме. После замены видеоэлемента выбор повторяется. Подключайте одинаковый фильм и перевод у всех участников.
- Автовоспроизведение со звуком может требовать нажатия ▶ у каждого участника. Недоступное у источника видео, DRM, ограничения доступа и блокировки сайта расширение не устраняет.
- Для других плеерных доменов требуется отдельное разрешение/обновление manifest после проверки. Автоматического доступа ко всем сайтам нет.
- Исходная папка и ZIP поддерживают локальные адреса и `https://vmeste.dadvanigeorgii.workers.dev`. Для дополнительного публичного адреса ZIP собирается с `VMESTE_APP_ORIGIN` или `node scripts/package-kinogo-extension.mjs --origin https://your-site.example`. Упаковщик добавляет только указанный origin в разрешения и проверки; исходники установленной копии не меняются. Установка расширения сама по себе не делает localhost доступным друзьям.

## Проверка и упаковка

Из корня проекта:

```sh
node --test tests/kinogo-extension.test.mjs tests/extension-package.test.mjs tests/extension-detection.test.mjs
node scripts/package-kinogo-extension.mjs
```

ZIP появляется в `public/downloads/vmeste-kinogo-extension.zip`. После изменения исходников переупакуйте архив и обновите расширение на странице управления расширениями. Основной браузерный сценарий требует установленного расширения: два профиля/браузера, ведущий и участник, подключение видео, запуск, пауза, перемотка, позднее подключение, закрытие комнаты и повторное подключение.
