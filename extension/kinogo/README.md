# Together Tonight — Киного

Расширение для Chrome/Edge 116+. В плеере комнаты оно помогает ведущему взять адрес видео из Киного. Друзья смотрят по приглашению. Для режима с отдельными вкладками Киного расширение нужно каждому участнику.

## Обновление до 0.4.1

Если расширение загружено из обновлённой папки проекта `extension/kinogo`, нажмите ↻ у него на `chrome://extensions` / `edge://extensions`. Для установки из ZIP сначала распакуйте новый архив с заменой файлов в установленную папку. Проверьте версию 0.4.1. Совместимая версия 0.4.0 носит прежнее имя «Вместе». Уже открытые страницы приложения подключаются автоматически; при необходимости нажмите значок «Together Tonight» → «Восстановить связь». После обновления со старой версии перезагрузите вкладку фильма, если в ней осталась старая панель. Выбор автовосстановления из 0.3.0 сохраняется.

### Смотреть в плеере комнаты

В комнате нажмите «Смотреть в комнате» → «Взять из Киного». Запустите нужный фильм и перевод. Когда появится пометка «ведущий» на плеере, вернитесь в комнату и нажмите «Взять из Киного» ещё раз. Расширение проверяет выбранный видеоэлемент и адреса плейлистов из его фрейма. Если найдено несколько потоков, ведущий выбирает и проверяет их в предпросмотре. «Открыть для всех» передаёт выбранный адрес участникам комнаты, сохраняя позицию фильма и приглашение.

Прямой адрес также можно вставить вручную без расширения. Для HLS с адресом без суффикса .m3u8 выберите формат HLS. Некоторые источники привязывают поток к браузеру, IP или времени и разрешают воспроизведение только на своём сайте. Участники получают видео непосредственно от источника. При истёкшей ссылке откройте «Источник видео» и проверьте новую. Кнопка «Вернуться к просмотру на Киного» возвращает исходную страницу фильма.

### Повторное открытие и пустая страница

Запуск скрипта расширения больше не считается загрузкой сайта: проверяется содержимое страницы или наличие видимого видео. Если Киного остаётся пустым около 10 секунд, расширение начинает восстановление. Пока фоновый процесс активен, работает короткий таймер; при его приостановке есть резервный alarm Chrome, который может сработать позже.

Если удаление данных Киного временно помогает, откройте значок расширения → **«Включить автовосстановление Киного»** и выдайте дополнительное разрешение. Этот выбор сохраняется. При зависании расширение автоматически сбросит кэш, cookies, localStorage, IndexedDB и service workers **только `https://kinogo.my` и `https://www.kinogo.my`**, затем повторит загрузку. Возможен выход из аккаунта Киного. Разрешение `browsingData` опциональное; без него работает только повторная загрузка без кэша. Выключение режима отзывает разрешение. В 0.3.1 включённый режим сразу применяет сброс, пропуская лишнюю пробную перезагрузку; сам сброс данных может занять дополнительное время.

Сброс не запускается при загруженной странице или выбранном плеере, в инкогнито, а также при других открытых вкладках Киного. Удаление cookies действует на весь домен kinogo.my, поэтому другие вкладки нужно сначала закрыть. Данные комнаты, стороннего плеера, других сайтов, история и пароли не удаляются. После автоматического восстановления нет бесконечных повторов; при ошибке есть пояснение и ручная повторная загрузка. Закрытие комнаты или переход на другой сайт отменяет последующую перезагрузку. Недоступность самого сайта или сети этот режим исправить не может.

Ссылки на страницы комментариев открывают основную страницу фильма. Обычные и инкогнито-вкладки не смешиваются.

Версия 0.2.0 поддерживает опубликованный сайт и в исходной папке, и в ZIP. Добавлены окно состояния по значку расширения, восстановление связи без перезагрузки комнаты, повторное использование открытого фильма, проверка установки/версии и сворачиваемая панель плеера. Обновление страницы комнаты не разрывает привязку фильма.

## Установка

1. Распакуйте ZIP или используйте эту папку `extension/kinogo`.
2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите режим разработчика → «Загрузить распакованное расширение» → выберите папку с `manifest.json`.
4. Откройте/перезагрузите комнату по адресу вашей сборки в том же профиле браузера. Для локальной версии это `http://127.0.0.1:5173` или `http://localhost:5173`.
5. Добавьте обычную ссылку на страницу фильма с `kinogo.my`, нажмите «Смотреть на Киного».
6. Запустите фильм. Играющее видео длительностью от 10 минут подключится после 3 секунд стабильного источника. Для коротких роликов или выбора другого видео нажмите «Подключить это видео» после рекламы.

У ведущего запуск, пауза и перемотка передаются через API комнаты. Участники следуют общему времени; звук остаётся локальным. Вкладку комнаты оставляйте открытой. При смене фильма подключите новую вкладку. «Отключить», закрытие комнаты или переход на другой фильм отключают сессию; вкладка Киного не закрывается.

## Доступ и ограничения

- Content scripts работают только на локальном приложении, `https://vmeste.dadvanigeorgii.workers.dev`, `kinogo.my`, `www.kinogo.my` и плеере `kinogomy.stravers.live`. В коде дополнительно проверяются origin, идентификатор комнаты, вкладка и выбранный фрейм. Разрешение `scripting` нужно для восстановления подключения в уже открытых вкладках этих сайтов.
- Ключ комнаты, сообщения чата и участники не передаются расширению или Киного. Авторизованные API-запросы выполняет вкладка приложения. Сервис расширения сам не делает сетевых запросов.
- Временная привязка вкладок хранится в `chrome.storage.session`. При перезапуске браузера подключите просмотр снова.
- Автоматический выбор консервативный: нужен играющий видимый HTML5-плеер, конечная длительность от 10 минут и стабильный источник в течение 3 секунд. Короткие ролики и неоднозначные случаи подключайте вручную. Это эвристика, а не распознавание рекламы. Автовыбор не заменяет уже выбранный плеер в другом фрейме. После замены видеоэлемента выбор повторяется. Подключайте одинаковый фильм и перевод у всех участников.
- Автовоспроизведение со звуком может требовать нажатия ▶ у каждого участника. Недоступное у источника видео, DRM, ограничения доступа и блокировки сайта расширение не устраняет.
- Для других плеерных доменов требуется отдельное разрешение/обновление manifest после проверки. Автоматического доступа ко всем сайтам нет.
- Исходная папка и ZIP поддерживают локальные адреса и `https://vmeste.dadvanigeorgii.workers.dev`. Для дополнительного публичного адреса ZIP собирается с `VMESTE_APP_ORIGIN` или `node scripts/package-kinogo-extension.mjs --origin https://your-site.example`. Упаковщик добавляет только указанный origin в разрешения и проверки; исходники установленной копии не меняются. Установка расширения сама по себе не делает localhost доступным друзьям.

## Проверка и упаковка

Из корня проекта:

```sh
node --test tests/kinogo-extension.test.mjs tests/extension-package.test.mjs tests/extension-detection.test.mjs tests/extension-recovery.test.mjs
node scripts/package-kinogo-extension.mjs
```

ZIP появляется в `public/downloads/vmeste-kinogo-extension.zip`. После изменения исходников переупакуйте архив и обновите расширение на странице управления расширениями. Основной браузерный сценарий требует установленного расширения: два профиля/браузера, ведущий и участник, подключение видео, запуск, пауза, перемотка, позднее подключение, закрытие комнаты и повторное подключение.
