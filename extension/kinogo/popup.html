Киного зависает при открытии?

Если страница остаётся пустой около 10 секунд, этот режим сбросит данные только kinogo.my и откроет фильм снова. Это может выйти из аккаунта Киного. Без этого режима выполняется только повторная загрузка без кэша.

Включается один раз. Работает только для пустой страницы, пока фильм ещё не подключён.

Сайт не видит расширение?

Нажмите «Восстановить связь». Комната и Киного должны быть открыты в этом же профиле Chrome. В инкогнито отдельно разрешите работу расширения в его настройках.
